# Lamu Girls High School Website

A school website built with Next.js, React, and Tailwind CSS for Lamu Girls High School.

## Pages

- **Home** — Hero section with school introduction
- **About Us** — School mission, vision, motto, and leadership
- **Admissions** — Admission requirements and application process
- **Events** — Upcoming events, recent highlights, and school calendar
- **Contact Us** — School address, phone, email, and office hours

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Next.js** 16 (App Router)
- **React** 19
- **Tailwind CSS** v4
- **CSS Modules** for component styling

## Project Structure

```
app/
  components/       — Shared components (Nav, HeroSection)
  contacts/         — Contact Us page
  events/           — Events page
  about/            — About Us page
  admission/        — Admissions page
  layout.js         — Root layout with navigation
  page.js           — Home page
  globals.css       — Global styles and Tailwind theme
```

## Deployment

Deploy on [Vercel](https://vercel.com) for the easiest Next.js hosting experience.
